# 🚀 EXCHANCE - صرافی و بازار هوشمند طلا، سکه، ارز و رمزارز

یک اپلیکیشن بومی اندروید فوق‌العاده مدرن، سریع و لوکس بر پایه **Jetpack Compose** و **Material 3** برای مشاهده قیمت لحظه‌ای دلار، انواع طلا و سکه، ارزهای بین‌المللی و رمزارزهای بازار همراه با نمودارهای تحلیلی و مبدل هوشمند ارزها.

---

## ✨ امکانات کلیدی (Features)

- **نرخ‌های لحظه‌ای و زنده (Live Market Prices):**
  - نرخ دلار آزاد، یورو، درهم امارات، پوند و سایر ارزهای شاخص (منبع TGJU.org)
  - انواع طلا: طلای ۱۸ عیار، طلای ۲۴ عیار، طلای دست دوم و مثقال آبشده
  - انواع مسکوکات بهار آزادی: سکه تمام امامی، بهار آزادی، نیم سکه، ربع سکه و سکه گرمی
  - رمزارزهای برتر: بیت‌کوین (BTC)، اتریوم (ETH)، تتر (USDT)، سولانا (SOL)، بایننس‌کوین (BNB)، تون‌کوین (TON) و ریپل (XRP)
- **نمودارهای تحلیلی پیشرفته (Interactive Recharts-style Area Charts):**
  - بازه‌های زمانی متنوع: ۲۴ ساعت، ۷ روز، ۱ ماه، ۳ ماه و ۱ سال
  - پیمایش لمسی (Touch Scrubbing & Crosshair) برای دیدن نرخ و بازدهی هر لحظه
  - خطوط راهنمای سقف و کف، میانگین و هیستوگرام حجم معاملات
- **مبدل همزمان و ماشین‌حساب صرافی (Currency Converter):**
  - تبدیل لحظه‌ای و دوطرفه بین تومان، ریال، دلار، تتر، طلا و رمزارزها
- **دیده‌بان دارایی‌ها و جستجو (Watchlist & Search):**
  - امکان افزودن دارایی‌های منتخب به فهرست علاقه‌مندی‌ها

## 🛠️ تکنولوژی‌ها و معماری (Tech Stack)

- **زبان:** Kotlin
- **رابط کاربری:** Jetpack Compose با طراحی اختصاصی Material Design 3
- **معماری:** MVVM + Clean Architecture + StateFlow
- **ارتباط با شبکه:** Retrofit & OkHttp & Moshi
- **چارتینگ:** بومی Compose با گرادیان‌های پیوسته و انیمیشن‌های روان بزیه
- **پایداری داده:** Coroutines & Jetpack DataStore / Room

## 📲 نحوه خروجی و اجرای پروژه

پروژه را می‌توانید مستقیماً در **Android Studio (نسخه Jellyfish یا Ladybug به بعد)** باز کرده و روی گوشی یا شبیه‌ساز اجرا کنید:

```bash
# بیلد پروژه و تولید نسخه Debug
gradle :app:assembleDebug
```

فایل APK خروجی در مسیر زیر قرار می‌گیرد:
```
app/build/outputs/apk/debug/app-debug.apk
```
